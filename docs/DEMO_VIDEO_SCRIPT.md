### Screencast Recording Tips

- Use Chrome in full-screen or presentation mode (hide bookmarks bar, extensions)
- If recording locally, use `localhost:5173`. If recording from Cloud Run, use the live URL.
- Screen record with macOS built-in (Cmd+Shift+5) or OBS
- Record each segment separately — easier to edit in CapCut
- For the split-screen segment (6), capture with system audio ON so Gemini's voice output is recorded
- For all other segments, audio is optional (subtitles carry the narrative)

### VEO3 Tips

- Generate each clip at highest available resolution
- Request 16:9 aspect ratio for all clips
- If a clip doesn't match the mood, regenerate with adjusted lighting/color notes
- Clips 1A, 1B, 2A are the most important for emotional impact — spend extra generations on these
- Clip 9A (Adelaide) may need multiple attempts to get the brand colors in the sky naturally

### Subtitle Style

- Font: Clean sans-serif (Montserrat, Inter, or similar in CapCut)
- Color: White with subtle black outline or shadow
- Position: Bottom center, with padding from edge
- Size: Large enough to read on mobile (minimum 48px at 1080p)
- Timing: Match natural reading pace — not too fast, not too slow
- Key phrases can be BOLD or highlighted in sky blue (#4cc9f0) for emphasis
